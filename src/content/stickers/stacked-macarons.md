Four chocolate macarons stacked vertically, photographed side-on so the ruffled feet and the filling between each shell are visible. Tall and narrow, with the repetition doing the work — it reads as a stack before it reads as a biscuit. Uniformly mid-brown, so it needs either a pale or a distinctly dark photo to separate from.
