Three stickers are enough to make a composition feel intentional if they do different jobs. The common problem is not the number of assets; it is giving all of them the same size, contrast and distance from the centre.

## Set a clear hierarchy

Choose one main accent, one supporting object and one small connector. In a 1080-pixel-wide practice canvas, try visible widths of 240, 150 and 80 pixels. Those are starting dimensions for this exercise, not export requirements.

![Three unequal accents forming a loose triangle around an open text area.](/guides/three-stickers.svg)

The main accent should make sense on its own. A bow, shell or flower can establish the mood. The smaller objects should reinforce it rather than introduce two unrelated themes.

## Protect the main subject

Place the photograph or message first. Mark the face, date or other detail that must stay unobstructed. Arrange the stickers outside that area, forming a loose triangle rather than a perfectly even row.

Try one larger object near the lower left, a smaller one near the upper right, and the connector nearer the caption. Vary the distances. Equal spacing can make the three objects look like navigation icons rather than decorations.

## Make one deliberate overlap

Let the supporting object overlap a small part of the main accent, while keeping the connector separate. This creates one group and one echo. If every object overlaps, the silhouettes can merge into an unreadable cluster.

Use the [collage maker](/collage-maker/) for a quick arrangement, or any layered editor when you need exact measurements. The numbers describe the visible objects, so account for [transparent padding](/blog/transparent-padding-sticker-size/) in the files.

## Run the removal test

Hide the smallest object. If the layout becomes clearer, leave it out or give it a useful role, such as directing attention toward the caption. A three-sticker exercise is not an obligation to retain all three.

Then view the design at roughly phone-preview size. The main message should still be noticed before the decoration. If the stickers dominate, reduce their size before lowering all their opacity.

For a second version, keep the same placement but change only the palette. This separates colour decisions from layout decisions and makes comparisons easier. The [two-colour palette exercise](/blog/two-color-sticker-palette/) gives a useful next constraint.
