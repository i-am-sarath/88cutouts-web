Mixed lettering works because the letters differ, but the word still needs a visible structure. If shape, size, colour, texture and rotation all vary independently, readers must decode each letter before they can understand the phrase.

## Choose one shared feature

Start with a common visible height, a restricted palette or a consistent paper tone. You only need one strong connection to make a group of different letterforms feel related.

![Mismatched paper letter tiles connected by a shared baseline and restrained palette.](/guides/letter-spacing.svg)

For a first exercise, keep the paper mostly cream and let the printed letter styles vary. In a second version, keep the type style calmer and vary the paper colours instead. Compare which version supports the message better.

## Control the strongest outlier

One black tile among pale scraps will attract attention. That can be useful if it emphasizes the first letter or an important word. If the dark tile lands in an arbitrary position, it may interrupt reading without adding meaning.

Before replacing it, try moving the emphasis to a more intentional part of the phrase. If the available letter set does not allow that, choose a lighter variant or use the dark tile's colour elsewhere in a small accent.

## Keep texture at a readable scale

Fine newspaper patterns and distressed edges can turn into visual noise when reduced. The printed letter should remain stronger than the texture behind it. If it does not, enlarge the heading or choose a simpler tile.

Do not add another busy sticker directly behind mixed lettering. Give the letters a quiet surface, then place decoration beside the phrase where it can establish mood without competing for the same space.

## Limit deliberate disorder

Try a mostly level baseline with one tilted tile. Compare it with a version in which every tile tilts. The first often feels more controlled because the exception has a clear relationship to the rest.

Export the stronger version and test at its actual use size. Check ambiguous forms such as `I`, `l`, `1`, `O` and `0`, particularly in names or dates.
