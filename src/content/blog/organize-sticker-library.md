A useful sticker folder should answer three questions: what is this asset, where did it come from, and which version can I safely edit? A folder containing hundreds of files called `image (2).png` answers none of them.

## Separate sources from finished work

Create three folders: `sources`, `projects` and `exports`. Sources hold original downloads. Projects hold editable compositions. Exports hold the flattened or transparent images you actually share.

![A source file branching into an editable project and a separately named final export.](/guides/export-flow.svg)

Do not overwrite the source after reducing its size or opacity. A small export cannot reliably stand in for the original when you later need a larger version.

## Name for recognition

Use a descriptive name such as `blue-satin-bow-88cutouts.png`. For projects, include the purpose and version: `maya-birthday-v2`. For a sequence, add a leading number: `01-arrival`, `02-details`, `03-sunset`.

Avoid storing every possible detail in the filename. A small text note beside the downloads can record the source page, download date and applicable licence. This is especially useful when assets come from several creators with different permissions.

## Organize by use, not every attribute

Start with a few broad groups such as paper, floral, lettering and frames. If you make dozens of deeply nested categories, you may spend more time filing than designing. A flower can belong in both a birthday and travel project without requiring duplicate source files.

Use project folders to group the assets used in a particular design, or keep a reference note listing their paths. When copying source files into a project for portability, preserve their original names and source notes.

## Review duplicates carefully

Two files with the same name may have different dimensions or transparency. Compare them before deleting either. Keep the version with the detail and permission information you need, not automatically the one with the largest byte count.

After a project is finished, retain the editable source and final export together. Back them up somewhere separate from the device you use for editing if the work matters to you.
